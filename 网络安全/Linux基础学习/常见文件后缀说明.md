# 常见文件后缀说明(网络安全/渗透测试视角)

## 前言:后缀到底是什么?

文件后缀（扩展名）**只是一个标签**，用来告诉操作系统"应该用什么程序打开我"，它**不会改变文件内部的真实二进制内容**。

- 操作系统靠后缀"猜"打开方式，但不会校验内容是否真的匹配
- 文件真正的类型由**文件头（Magic Number）**决定，例如：
  - PNG 图片开头固定是 `89 50 4E 47`
  - ZIP 压缩包开头固定是 `50 4B 03 04`
  - PDF 文件开头固定是 `%PDF`
- 把 `.zip` 重命名成 `.jpg`，内容依然是 zip 结构，改回后缀依然能正常解压
- **渗透测试中的"后缀绕过"** 正是利用了"系统只看后缀不看内容"这个弱点：把 webshell 伪装成图片后缀骗过简单校验，再配合其他漏洞让服务器按真实内容解析执行

> 实用建议：拿到不认识的文件，先用 `file 文件名`（Linux）或 `xxd`/`hexdump` 查看文件头，判断真实类型，而不是只信后缀。

## 一、基础文档/数据类

| 后缀 | 含义 | 说明 |
|---|---|---|
| `.txt` | 纯文本 | 无格式 |
| `.md` | Markdown | 轻量标记语言 |
| `.json` | JSON 数据 | 键值对结构，API 常用，渗透时常需分析接口返回的 json |
| `.xml` | XML 数据 | 标签结构，配置文件、SOAP 接口常用 |
| `.yaml` / `.yml` | YAML 配置 | Docker、K8s、CI/CD 配置文件常用格式 |
| `.csv` | 表格数据 | 逗号分隔 |
| `.log` | 日志文件 | 渗透测试中分析日志找线索非常重要 |

## 二、压缩/打包类

| 后缀 | 说明 |
|---|---|
| `.zip` | 常见压缩格式 |
| `.tar` | Linux 打包（不压缩） |
| `.tar.gz` / `.tgz` | Linux 打包 + gzip 压缩，最常见 |
| `.rar` | WinRAR 压缩 |
| `.7z` | 7-Zip 压缩，压缩率高 |

## 三、渗透测试/网安重点关注

### Web 相关

| 后缀 | 说明 |
|---|---|
| `.php` / `.jsp` / `.asp` / `.aspx` | 服务端脚本文件，分别对应 PHP/Java/ASP.NET，判断目标技术栈的关键线索 |
| `.war` | Java Web 应用打包文件（部署到 Tomcat），常藏有 `WEB-INF/web.xml` 等敏感信息 |
| `.htaccess` | Apache 目录级配置文件（无主文件名，以点开头），常用于权限控制，也常被用来 getshell |
| `.conf` | 通用配置文件后缀，如 `nginx.conf` |

### Webshell / 免杀相关

| 后缀 | 说明 |
|---|---|
| `.jsp` / `.jspx` | Java 环境下的 webshell 常用后缀 |
| `.phtml` / `.php5` / `.pht` | PHP 的"冷门"可执行后缀，常用于绕过黑名单过滤（如目标只过滤了 `.php`） |

### 密钥/证书类

| 后缀 | 说明 |
|---|---|
| `.pem` | Base64 编码的证书/密钥文件，SSH 免密登录常用 |
| `.key` | 私钥文件 |
| `.crt` / `.cer` | 证书文件 |
| `.pfx` / `.p12` | 证书 + 私钥打包格式，常见于 Windows 环境 |

### 数据库相关

| 后缀 | 说明 |
|---|---|
| `.sql` | SQL 脚本/数据库导出文件，拿到 shell 后常查找，可能含数据库账号密码 |
| `.db` / `.sqlite` / `.sqlite3` | SQLite 数据库文件，体积小，常内嵌在 App/小型系统中 |

### 内存取证/漏洞利用相关

| 后缀 | 说明 |
|---|---|
| `.pcap` / `.pcapng` | 抓包文件（Wireshark 用），CTF 流量分析题标配 |
| `.dmp` | 内存转储文件，提权和漏洞分析常用 |
| `.elf` | Linux 可执行文件格式（无后缀也可能是 ELF，需靠 `file` 命令判断） |
| `.so` | Linux 动态链接库，类似 Windows 的 `.dll`，逆向分析常见目标 |

### Windows 相关

| 后缀 | 说明 |
|---|---|
| `.exe` | 可执行文件 |
| `.dll` | 动态链接库 |
| `.bat` | 批处理脚本 |
| `.ps1` | PowerShell 脚本，内网渗透/免杀常用 |
| `.reg` | 注册表导入文件 |

### 脚本/自动化

| 后缀 | 说明 |
|---|---|
| `.sh` | Shell 脚本（Linux） |
| `.py` | Python 脚本 |
| `.yaml` | Ansible/K8s 部署配置 |
