## ✨ 这个库有什么不一样

**1. 先学开发，再学攻防。**
想看懂别人的漏洞，得先看懂别人的代码。所以这里有整整 20 篇 JavaEE / JS / PHP 开发笔记——
学它们不是为了写业务代码，而是为了明白**漏洞是在代码的哪一环长出来的**。

**2. 主干是完整的一条线，不是零散知识点。**

```
Linux 基础 → 读懂 Web 前后端代码 → Web 攻防实战 → 代码审计 → 信息收集打点
```

**3. 工具笔记带"工作流"，不是参数罗列。**
nuclei / ffuf / subfinder / httpx / naabu / MobSF 这些工具，除了用法还整理了**怎么串起来用**，
例如「web 资产收集到漏洞验证」的完整链路。

**4. 有配套的实战资料。**
PortSwigger Web Security Academy 全漏洞类型笔记（路径穿越、访问控制、认证、SSRF、文件上传、OS 命令注入）、
SRC 漏洞挖掘经验、以及一份渗透测试英语词汇速记表（看英文文档和工具的救星）。
